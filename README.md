# sg-modules-assets

Star Glitcher animation assets (`.anim`) used by the BlaaBlaa Reanim module `StarGlitcher.lua`.

The module points at these files with the host's `filename@url` asset syntax:

```
StarGlitcher_<mode>_idle.anim@https://raw.githubusercontent.com/Jskfhggjxu/sg-modules-assets/main/anims/StarGlitcher_<mode>_idle.anim
```

20 modes x (idle, walk) = 40 files, all under `anims/`.
